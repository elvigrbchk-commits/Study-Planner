
# Study Planner

## Project Description

Study Planner is a responsive website that helps students organize subjects, tasks, deadlines, and study progress.

## Team Members

- Elvira - Dashboard and Calendar
- Aruzhan - Tasks and Progress
- Talshyn - Subjects and About/Contact Us, CSS

## Pages

1. Dashboard
2. Subjects
3. Tasks
4. Calendar
5. Progress
6. About Us
7. Contact Us

## Final Project Features

### 1. API Integration
- Open Library API
- Search for books by topic
- Fetch data using async/await
- Loading, success, empty, and error messages

### 2. Object-Oriented Programming
- Task class
- Subject class
- Constructors, properties, and methods

### 3. LocalStorage
- Save subjects and tasks
- Save study goals and daily focus
- Restore saved data after refreshing

### 4. CRUD Operations
- Add, view, edit, and delete subjects
- Add, view, edit, and delete tasks
- Confirmation before deleting

### 5. Search and Filtering
- Search subjects
- Filter completed and pending tasks

### 6. Dashboard and Statistics
- Total tasks
- Completed tasks
- Pending tasks
- Overdue tasks
- Overall progress bar
- Clickable statistics cards

### 7. Other Features
- Monthly and weekly calendar
- Study goals
- Progress by subject
- Form validation
- Responsive design
- jQuery animations

## Technologies

- HTML5

## How to Run

1. Download or clone the repository.
2. Open the project in VS Code.
3. Open index.html using Live Server.
4. Navigate between pages.
5. Add subjects and tasks.
6. Check progress and calendar.
7. Search for books on the Tasks page.
8. Refresh to test localStorage.
