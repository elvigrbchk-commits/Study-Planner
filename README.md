
# Study Planner

## Project Description

Study Planner is a responsive website that helps students manage subjects, tasks, deadlines and study progress.

## Team Members

- Elvira - Dashboard and Calendar
- Aruzhan - Tasks and Progress
- Talshyn - Subjects and About Us

## Pages

1. Dashboard
2. Subjects
3. Tasks
4. Calendar
5. Progress
6. About Us
7. Contact Us

## Features

- Add and delete subjects
- Add and delete tasks
- Mark tasks as completed
- Filter completed and pending tasks
- Form validation
- Monthly and weekly calendars
- Progress tracking
- Study goals and daily focus
- LocalStorage for saving data
- Responsive navigation
- jQuery animations

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery
- LocalStorage

## How to Test

1. Open index.html using Live Server.
2. Go to Subjects and add a new subject.
3. Go to Tasks and add a new task.
4. Mark the task as completed.
5. Check the Calendar and Progress pages.
6. Refresh the page to check saved data.
7. Test the website in mobile view.
