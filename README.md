# Study-Planner

## Project Description

Study Planner is a multi-page responsive website designed to help students
organize their subjects, tasks, calendar and academic progress.

## Pages

- Dashboard
- Subjects
- Tasks
- Calendar
- Progress

## Features

- Task management
- Subjects overview
- Academic calendar
- Progress tracking
- Responsive design
- HTML table
- HTML form
- CSS Flexbox
- CSS Grid
- Bootstrap Grid
- Bootstrap utility classes

## Technologies

- HTML5
- CSS3
- Bootstrap 5
